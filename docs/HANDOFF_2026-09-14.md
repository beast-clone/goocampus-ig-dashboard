does NOT deploy. Until the repo is re-linked in Netlify (Build & deploy → Manage repository →

`NETLIFY_AUTH_TOKEN` from `.env.local`):

```

```

`--build` runs `npm run build` + @netlify/plugin-nextjs locally and uploads the result.
