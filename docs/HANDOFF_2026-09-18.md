## 6. Deploying

Git auto-deploy on Netlify is broken (stale deploy key) → deploy with the CLI. **Don't build on the
exFAT drive** — the Netlify Next plugin dies on a `._*` sidecar file. Instead:

```bash
rsync -a --exclude='._*' --exclude=.next --exclude=.netlify --exclude=.git <repo>/ /tmp/deploy-src/
cd /tmp/deploy-src && export NETLIFY_AUTH_TOKEN=<from .env.local>
npx --yes netlify-cli@latest deploy --prod --build --site a138e312-a725-46c3-9eaa-fe163ba1b1f9
rm -rf /tmp/deploy-src     # it contains .env.local
git push origin feat/dashboard-reskin:main
```
