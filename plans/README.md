# Improve plans — Content Review + My Day

_Generated by the `improve` skill (shadcn), 2026-07-19 — focused audit of the Content Review + My Day surface on the current (19-July) code. Read-only advisory; each plan is self-contained so a fresh executor with zero session context can run it._

## State of the area

The Content Review + My Day pipeline is functionally solid but carries one genuine data deadlock and a cluster of state-sync/trust-boundary defects. The single highest-value fix (P0) is that both gate routes (content-review, scheduler/to-schedule) compute "has a creative" only from mh_posts.media_urls/output_link and ignore mh_attachments, so any post whose only creative was uploaded through the task-detail modal can never be approved or scheduled — a hard deadlock on the happy path. Beyond that, three P1 correctness bugs cause visible state churn (claim reconcile dedupes against the viewer not the claimer → duplicate cards; unclaimed approved videos are returned in both tasks and pool → handoff reverts; the design auto-handoff owner-reassign is a separate unchecked write that can silently diverge status from ownership). The remaining items are decision-gated hardening (server-side review-gate enforcement, non-spoofable actor identity, takeover race, duplicate DB-trigger logging), ~150 lines of confirmed-dead demo code, and UX/test-baseline polish. Recommendation: land Plan 1 (P0 deadlock) immediately, then the three P1 state-sync fixes, before touching the decision-gated security/cleanup work.
